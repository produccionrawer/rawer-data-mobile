RAWER DATA v9.19 - Ventas y entregas de hoy con ventas particulares

Cambios sobre v9.18:
- En Ventas Tiendanube > Hoy · ventas y entregas ahora se integran también las ventas particulares/mayoristas.
- La pestaña Entregas de hoy muestra Tiendanube + Particular / Mayorista en una sola tabla, identificando el canal.
- La pestaña Ventas de hoy también combina ambos canales.
- El filtro por depósito aplica a ambos canales.
- Las métricas superiores y el resumen por depósito contemplan Tiendanube + particulares.
- Para ventas particulares, el estado pendiente considera despachos físicos y regularizaciones históricas de comandas ya entregadas.
- No modifica stock real ni cambia la lógica de ventas; es una mejora de visualización operativa.

Importante:
- Una venta particular figura como entrega de hoy cuando su campo fecha_entrega es la fecha actual.
- Las ventas mayoristas importadas desde EcommApp conservan la fecha_entrega definida por el importador vigente.
