RAWER DATA v9.20 MOBILE BETA

Base: v9.19 (preservada sin modificaciones en su ZIP original).

Objetivo de esta beta:
- Probar Rawer Data desde celular/tablet sin migrar todavia la base de datos.
- Mantener una sola aplicacion y una sola base.
- Simplificar la navegacion segun tarea operativa.

Cambios:
- CSS responsive para pantallas chicas.
- Botones y campos mas grandes para uso tactil.
- Nuevo switch lateral: "Modo movil beta".
- Perfiles de interfaz:
  * Operaciones
  * Despachos
  * Produccion
  * Batch MP
- Accesos directos:
  * Despachos abre directamente Carga diaria > Despachos.
  * Cargar produccion abre directamente Carga diaria > Produccion.
  * Cargar Batch MP abre directamente Carga diaria > Batchs MP.
- El modo normal completo sigue disponible al desactivar el switch.

IMPORTANTE:
- Esta beta NO agrega aun autenticacion real ni permisos de seguridad por usuario.
- Los perfiles solo simplifican/ocultan la navegacion de la interfaz.
- No se modifican las reglas de stock ni la estructura de datos por activar el modo movil.
- Probar primero con una copia de la base de datos antes de usarla en produccion multiusuario.
